# Code of Conduct

We want this project to be welcoming and useful to everyone. Participants are
expected to be respectful, constructive, and considerate of different
backgrounds and experience levels.

Harassment, discrimination, personal attacks, doxxing, and deliberately
disruptive behavior are not acceptable.

Report conduct concerns privately through the repository maintainer's GitHub
profile or the private security/contact mechanisms described in the
repository settings. Reports will be handled discreetly and fairly.

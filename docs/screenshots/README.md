# Beads visual captures

These images are captures of the live Beads panel in the BB desktop app,
recorded from the local `bb-beads` project on 2026-08-17. They show the actual
current project issue state, including its titles, statuses, counts, and the
visible owner label. Review that project data again before publishing a future
release or sharing the images outside this repository.

The captures contain no credentials or filesystem paths, but they are real
project data rather than synthetic illustrations. They document desktop
layouts only; no narrow/mobile capture was available because the browser
runtime and paired handset were unavailable. Use the mobile release checklist
for the remaining live checks.

The dependency-graph capture is intentionally scrolled into a dense middle
region of the large graph so that several real issue branches and their edges
are visible at once; it is not intended to represent the graph's top-left
origin.
